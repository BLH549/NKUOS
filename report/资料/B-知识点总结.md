## 1. 本实验的逻辑

启动页表提供最初可运行的地址映射；设备树告诉内核 RAM 的位置；`page_init()` 生成 Page 元数据并排除保留页；页分配器组织可用连续页；SLUB 将页进一步划分成小对象。这条链使“硬件存在 RAM”转变为“内核可以按页和按对象申请、释放 RAM”。

页分配策略与地址翻译机制分工不同：前者决定哪段物理内存可分配，后者决定一个虚拟地址如何访问既定物理地址。更换 Best-Fit 为 Buddy 并不自动建立新的进程页表。

## 2. 对应关系、含义与差异

| 实验知识点 | OS 原理中的含义 | 本实验如何体现及差异 |
| --- | --- | --- |
| 设备树内存探测 | 通过固件/启动协议获得硬件资源布局 | QEMU 传入 DTB，内核读取首段 RAM；实际 OS 还需解析多 RAM bank、reserved-memory、UEFI 内存图等 |
| 保留页与初始化布局 | 区分可管理内存、实际可分配内存及元数据开销 | 固件、内核和 Page 数组保留，剩余完整页才能注册；RAM 总容量不等于空闲页数 |
| Page 描述符 | 用软件元数据管理页帧状态、引用和空闲关系 | 每个物理页对应一个 Page；Page 数组地址是虚拟地址，不能直接当物理页内容地址 |
| 物理页号与直接映射 | 从地址提取页号，并用固定映射访问物理内存 | `page2ppn/page2pa` 与固定 `va_pa_offset` 协作；本实验固定映射不是任意进程地址空间 |
| First-Fit | 在满足要求的空闲区中选择首次遇到者 | 按地址链表找到首块，拆分后可双向合并；查找与链表长度相关，可能产生外部碎片 |
| Best-Fit | 选择满足需求的最小空闲区 | A 扫描所有候选块，减少本次剩余空间，但可能积累小碎片；不保证长期最优或消除外部碎片 |
| Buddy | 按幂次块管理连续物理页，利用二进制伙伴高效拆合 | B 使用按物理页号对齐的阶链表；仅同阶伙伴合并。取整带来内部碎片，维护逐页标志也增加成本 |
| SLUB / 对象缓存 | 在页之上复用同类小对象槽位，减少每次整页分配的浪费 | B 的类别、partial/full、空页归还体现两层架构；位图、全局链表与 Linux 每 CPU freelist 并不相同 |
| 内部与外部碎片 | 已分配块内部浪费，与空闲区域无法满足连续请求是两种问题 | Buddy 3 页申请占 4 页是内部碎片；两个相邻非伙伴块不能合成需要的块体现对齐/块结构限制；Best-Fit 也会有零散小块 |
| Sv39 多级页表 | VPN 索引页表，叶子项给出物理页号与权限 | 启动映射可能使用大页，翻译未必遍历三层；具体页表项和地址转换案例由 C 的调试证据确认 |
| TLB 与刷新 | 缓存地址翻译，页表变更后需处理旧缓存 | 启动映射调整后执行刷新；QEMU 软件 TLB 和硬件 TLB 的实现细节不同，不能把模拟器的数据结构等同于真实 CPU |
| 断言、不变量与测试 | 用局部条件和外部模型约束内存管理状态 | B 同时检查地址、数据、页数和预期失败；有限测试不能证明所有输入与并发情形正确 |

## 3. 本实验未完整覆盖的重要知识

1. **进程独立地址空间与隔离。** 当前内核采用固定启动映射，没有完整的用户/内核隔离、页表按进程切换和访问权限管理。
2. **按需分页、缺页处理和页面置换。** 本实验建立分配能力，没有实现完整的磁盘后备、换入换出、LRU/Clock 或工作集管理。
3. **写时复制与共享内存。** Page 中存在引用计数，但本实验没有实现 fork 的共享页、写保护、COW 缺页复制和共享内存生命周期。
4. **多核与中断并发。** 无锁的阶链表和 slab 位图只适用于本轮顺序调用；真正内核需要锁、关中断、每 CPU 缓存和跨核 TLB shootdown。
5. **NUMA、热插拔和物理内存分区。** 实验按固定基址和管理上界组织首段 RAM，没有跨节点分配策略、DMA zone、迁移与热插拔。
6. **安全与健壮性。** 断言能拒绝部分错误释放，但不能防止任意内核越界写、所有悬空指针、元数据破坏或恶意并发；未提供 quarantine、红区与通用内存标记。

## 4. AI 协作的实际经验

接口语义必须先写清楚。Buddy 的“请求 3 页、占用 4 页、按 3 页参数释放”若不明确，SLUB 和测试就可能按不同含义计算页数。本轮把请求大小、实际占用和空闲块阶数分别记录和解释。

测试应有独立的预期来源。随机模型逐页标记占用，并扫描对齐区间判断是否应分配成功，没有复制 Buddy 的链表查找流程。对象测试实际写入并复查数据，而非只确认返回指针非空。

运行结论需要准确限定。主机 ASan/UBSan 支持检查模拟缓冲区内的越界和未定义行为，QEMU 支持确认 RISC-V 集成运行，教师 20/20 支持确认其覆盖的初始化与 Best-Fit 检查；三者各有范围。B 本人复现和截图已于 2026-10-24 完成，答辩和全组交叉检查仍需按验收清单完成。
